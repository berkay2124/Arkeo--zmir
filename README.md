# 🏛️ Arkeo İzmir - İzmir Arkeolojik Miras Platformu

Profesyonel, modern ve kusursuz arkeoloji platformu.

## ✨ Özellikler

### 🎨 Profesyonel Tasarım
- Modern, responsive tasarım (tüm cihazlarda mükemmel)
- Profesyonel renk paleti ve tipografi
- Smooth animasyonlar (AOS kütüphanesi)
- Parallax efektler ve modern CSS
- Hover efektleri ve geçişler

- **Renk Paleti**: Antik terracotta ve Akdeniz renkleri

- **Layout**: CSS Grid & Flexbox
- **Responsive**: Mobile-first yaklaşım
