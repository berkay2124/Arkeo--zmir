

**GitHub Pages (Free)**
```bash
1. Create GitHub repository
2. Upload all files
3. Settings > Pages > Deploy from main branch

```

**Netlify (Free, Easy)**
```

2. Drag & drop the Hologrart folder

```

```bash
cd Hologrart

```

## 🔧 Customization Guide

### Adding New Sites

**Edit `js/sites-data.js`:**
```javascript
{
    id: 13,  // Increment ID
    name: "New Site Name",
    turkish: "Turkish Name",
    district: "District Name",
    periods: ["Classical", "Roman"],
    mainPeriod: "Roman",
    type: "Ancient City",
    category: "major",
    coordinates: { lat: 38.1234, lng: 27.5678 },
    // ... complete all fields following existing examples
}
```

### Changing Colors

**Edit `css/main.css` (lines 13-20):**
```css
:root {
    --color-primary: #c17817;        /* Your brand color */
    --color-secondary: #2c5f7c;      /* Accent color */
    /* Adjust other colors as needed */
}
```

### Adding Your Photos

```bash
1. Add images to /images/ folder
2. Update site.images array in sites-data.js:
   images: [
       "images/ephesus-1.jpg",
       "images/ephesus-2.jpg"
   ]
```
